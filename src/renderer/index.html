Why won't my Burp extension load?

Burp Error Checker reads your Burp Suite settings, finds every extension that is not loaded and tests its files the same way Burp does, so you see the real cause and how to fix it.

How the checks work

Burp keeps the list of installed extensions in its user settings file. Each entry has the file Burp loads, the extension type and whether it is currently loaded. When an extension fails, Burp unticks it and shows the error once in its Errors tab. This app tells you why, without starting Burp.

Status meanings

  • Error A definite problem that stops the extension from loading.
  • Warning Something that very likely breaks it.
  • No cause found The files are fine. The extension is switched off, or fails while running (read its Errors tab in Burp).
  • Loaded Burp has it running.

Java extensions (.jar)

The archive is opened and every class is read. Burp needs a class named burp.BurpExtender (legacy API) or a class implementing burp.api.montoya.BurpExtension (Montoya API). The class-file version is compared with the Java runtime bundled with Burp.

Python extensions (.py)

The main file and every local module it imports are compiled with the Jython JAR Burp is set to use. Compiling only checks syntax; no extension code runs. Imports are matched against Jython's standard library, the extension folder and Burp's "Folder for loading modules".

Where the data comes from

Burp writes the settings file when its settings change. If you just loaded or unloaded something in Burp, scan again to see the new state.
